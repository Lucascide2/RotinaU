# Remix of RotinaU 2

HU16 — Antecipar e concluir sessões da semana

Como estudante universitário,
quero marcar como concluída uma sessão planejada para outro dia da mesma semana,
para registrar que antecipei aquele estudo e manter meu planejamento atualizado.

Critérios de aceitação

O estudante deve conseguir visualizar as sessões planejadas para a semana.

O estudante deve poder marcar como concluída uma sessão antes do dia e horário originalmente planejados.

O sistema deve registrar a sessão como concluída antecipadamente.

A sessão deve apresentar uma identificação visual diferente de uma sessão concluída no horário planejado.

O sistema deve informar o dia em que a sessão foi efetivamente realizada.

A sessão antecipada deve continuar sendo contabilizada como uma sessão concluída.

A antecipação deve ser considerada nos indicadores de progresso e de dias estudados.

A conclusão antecipada de uma sessão não deve gerar uma sinalização de atraso ou sessão não realizada.

O estudante deve poder visualizar tanto a data planejada quanto a data em que realizou a sessão.
